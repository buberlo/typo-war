# Typo War

> A keyboard duel where autocorrect fights for its own side.

A local two-player game where players type words to fire attacks, block with nouns, and land critical hits with punctuation. The twist is an aggressive autocorrect system that can rewrite your shot mid-flight, turning a harmless word into a powerful or embarrassing one. It is a chaotic word-shooter built around the terror of predictive text.

## Features
- Split-screen keyboard duels where typed words launch projectiles
- Nouns are shields, verbs are hits, and punctuation adds crits
- An autocorrect engine can rewrite your word mid-flight or into a dud
- Round-end meme card lists your most embarrassing corrections

## Stack
- Phaser
- TypeScript

## Getting started
```
npm install && npm run dev
```
